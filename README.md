# Adoyle-h Tap

## How do I install these formulae?

`brew install adoyle-h/tap/<formula>`

Or `brew tap adoyle-h/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "adoyle-h/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
